# Information technology - City data model - Part 3: Service-level concepts for transport - Rail network pattern

This ontology specifies the service-level concepts for rail transport in the city data model.

This pattern imports the following files:

- [https://w3id.org/citydata/part3/v1/TransportNetworkPattern](https://w3id.org/citydata/part3/v1/TransportNetworkPattern)

This pattern consists of the following classes:

- [Rail Corridor](RailCorridor.md)
- [Rail Network](RailNetwork.md)
- [Rail Section](RailSection.md)
- [Track Link](TrackLink.md)
- [Track Segment](TrackSegment.md)

The formal definition of this pattern is available in TURTLE Syntax in two files, the [core semantics](../RailNetworkPattern.ttl) and the SHACL [restrictions](../RailNetworkSHACL.ttl).
