# Information technology - City data model - Part 3: Service-level concepts for transport - Road network pattern

This ontology specifies the service-level concepts for road transport in the city data model.

This pattern imports the following files:

- [https://w3id.org/citydata/part3/v1/TransportNetworkPattern/](https://w3id.org/citydata/part3/v1/TransportNetworkPattern/)

This pattern consists of the following classes:

- [Road](Road.md)
- [Road Lane](RoadLane.md)
- [Road Link](RoadLink.md)
- [Road Link User Type](RoadLinkUserType.md)
- [Road Network](RoadNetwork.md)
- [Road Section](RoadSection.md)
- [Road Segment](RoadSegment.md)
- [Vehicle Flow Rate](VehicleFlowRate.md)
This module defines the following properties:

- [capacity](../properties/capacity.md)
- [maxLanes](../properties/maxLanes.md)
- [next](../properties/next.md)
- [numLanes](../properties/numLanes.md)
- [pavementType](../properties/pavementType.md)
- [previous](../properties/previous.md)
- [primaryUser](../properties/primaryUser.md)
- [RoadNetworkDataProperty](../properties/RoadNetworkDataProperty.md)
- [RoadNetworkObjectProperty](../properties/RoadNetworkObjectProperty.md)
- [speedLimit](../properties/speedLimit.md)
- [travelTime](../properties/travelTime.md)
- [usedBy](../properties/usedBy.md)
- [userCategory](../properties/userCategory.md)
- [uses](../properties/uses.md)
- [width](../properties/width.md)


The formal definition of this pattern is available in TURTLE Syntax in two files, the [core semantics](../RoadNetworkPattern.ttl) and the SHACL [restrictions](../RoadNetworkSHACL.ttl).
