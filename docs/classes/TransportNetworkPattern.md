# Information technology - City data model - Part 3: Service-level concepts for transport - Transport network pattern

This ontology specifies the transport network pattern of the transport service of the city data model.

This pattern imports the following files:

- [https://w3id.org/citydata/part2/v1/TransportInfrastructurePattern](https://w3id.org/citydata/part2/v1/TransportInfrastructurePattern)
- [https://w3id.org/citydata/part3/v1/CorePattern](https://w3id.org/citydata/part3/v1/CorePattern)

This pattern consists of the following classes:

- [Junction](Junction.md)
- [Network Element](NetworkElement.md)
- [Scheduled Code](ScheduledCode.md)
- [Transport Network](TransportNetwork.md)
- [Transport Network Thing](TransportNetworkThing.md)
- [Transport Node](TransportNode.md)
- [Travelled Way](TravelledWay.md)
- [Travelled Way Lane](TravelledWayLane.md)
- [Travelled Way Link](TravelledWayLink.md)
- [Travelled Way Section](TravelledWaySection.md)
- [Travelled Way Segment](TravelledWaySegment.md)

This module defines the following properties:

- [allowedDirections](../properties/allowedDirections.md)
- [designator](../properties/designator.md)
- [egress](../properties/egress.md)
- [from](../properties/from.md)
- [ingress](../properties/ingress.md)
- [status](../properties/status.md)
- [timeInterval](../properties/timeInterval.md)
- [to](../properties/to.md)
- [TransportNetworkDataProperty](../properties/TransportNetworkDataProperty.md)
- [TransportNetworkObjectProperty](../properties/TransportNetworkObjectProperty.md)
- [travelCorridorSegment](../properties/travelCorridorSegment.md)


The formal definition of this pattern is available in TURTLE Syntax in two files, the [core semantics](../TransportNetworkPattern.ttl) and the SHACL [restrictions](../TransportNetworkSHACL.ttl).
