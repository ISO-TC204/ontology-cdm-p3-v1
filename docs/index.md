# Information technology - City data model - Part 3: Service level concepts - Transport

This ontology specifies the service-level concepts defined for the transport service of the city data model.

The Information technology - City data model - Part 3: Service level concepts - Transport consists of the following patterns:

- [Core](classes/CorePattern.md)
- [Micromobility Network](classes/MicromobilityNetworkPattern.md)
- [Pedestrian Network](classes/PedestrianNetworkPattern.md)
- [Public Transport System](classes/PublicTransportSystemPattern.md)
- [Rail Network](classes/RailNetworkPattern.md)
- [Road Network](classes/RoadNetworkPattern.md)
- [Transport Alert](classes/TransportAlertPattern.md)
- [Transport Network](classes/TransportNetworkPattern.md)
- [Travel Corridor](classes/TravelCorridorPattern.md)
